# Data

This folder documents the dataset used in the DataCo Supply Chain
Analytics project. The raw CSV file is not included in this
repository due to its file size. Instructions for obtaining the
dataset are provided below.

---

## Dataset

**Name:** DataCo Smart Supply Chain Dataset
**Source:** Kaggle
**URL:** https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis

---

## How to Obtain the Dataset

1. Visit the Kaggle link above
2. Sign in to your Kaggle account (free registration required)
3. Click **Download** to download the dataset as a ZIP file
4. Extract the ZIP — the primary file is `DataCoSupplyChain.csv`
5. Import the CSV into Microsoft SQL Server using the SSMS
   import wizard
6. Name the database `DataCo` and the table
   `DataCoSupplyChainDataset`
7. Run `scripts/01_schema.sql` followed by
   `scripts/02_data_cleaning.sql` to prepare the data
   for analysis

## Data Quality Notes

| Issue | Detail | Resolution |
|---|---|---|
| 7 columns imported as tinyint | SSMS assigned tinyint to INT columns causing overflow errors | Corrected to INT via ALTER COLUMN in 02_data_cleaning.sql |
| Late_delivery_risk imported as BIT | SUM() not supported on BIT in SQL Server | CAST AS INT applied in all analysis queries |
| Zero nulls across all analytical columns | Full dataset confirmed complete | No imputation or row exclusion required |
| Caguas, Puerto Rico concentration | 66,770 orders (37% of sales) from one city | Flagged as probable data anomaly — investigate before city-level analysis |
| Uneven year coverage per market | Some markets missing entire years of data | Noted in Module 4 — year-over-year market comparisons treated with caution |
| 2018 partial year | Only 2,123 orders in 2018 | Treated as partial year — excluded from trend conclusions |

## Cleaned View

All analysis in this project queries the cleaned view
`DataCo.dbo.vw_DataCo_Cleaned` rather than the raw table
directly. The view:

- Excludes all PII columns
- Excludes non-analytical columns (Product_Description,
  Product_Image, Latitude, Longitude, Order_Zipcode)
- Adds `Is_Late_Delivery` — derived binary late delivery flag
- Adds `Delivery_Gap_Days` — derived delivery gap in days
- Reflects all 180,519 rows from the raw table unchanged

The view is created in `scripts/02_data_cleaning.sql`.

## Why the Raw CSV Is Not Included

GitHub recommends keeping repository files under 50MB.
The DataCo CSV exceeds this threshold. Hosting large
datasets in version control also creates unnecessary
repository bloat and slows clone times for anyone
reviewing the project.

The dataset is freely available on Kaggle at the link
above and can be imported into any SQL Server instance
in minutes using the instructions provided.
